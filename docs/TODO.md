# 26. 10. 15. Codex's suggestion

## 연구 수행 계획

제안서의 질문과 방법을 다음 순서로 구현한다. 먼저 자료의 범위와 품질을 확인하고, 분석 경계를 확정한 뒤, 공간 전처리와 집계를 진행한다. AIS 항적 수를 실제 입출항 횟수나 선박 간 조우로 해석하지 않는다는 제안서의 한계를 결과 문서와 시각화에도 명시한다.

1. **자료 확보 및 표본 점검**: NOAA Office for Coastal Management의 *AIS Vessel Tracks 2024*를 출처로 기록한다. 공식 항적 인덱스의 전국 ZIP 원본(약 6.81 GiB)을 `data/raw/`에 저장했으며, 내부에는 GeoPackage 파일이 있다. 별도의 월별 GeoParquet 배포본도 있으므로 이후 메타데이터와 처리 여건을 비교해 기준 형식을 확정한다. GeoPackage 레이어, 좌표계, 필드를 점검한 뒤 Norfolk/Hampton Roads 분석 경계에 걸치는 항적만 지역 자료로 추출한다. 항적 시작월, MMSI, 선종 분류 및 결측·중복·비정상 경로를 점검한다.
2. **분석 경계·좌표계 확정**: NOAA 전자해도 등을 참고해 Norfolk/Hampton Roads 진입로 및 접근수역 경계를 벡터 파일로 확정한다. 거리·면적 계산에는 해당 지역에 적합한 미터 단위 투영좌표계를 사용한다. 경계 파일, 좌표계(EPSG), 포함 기준(항적과 경계의 교차 여부)을 설정값으로 관리한다.
3. **전처리**: 좌표·시간·MMSI·선종 유효성을 검사하고, 분석 경계와 교차하는 항적을 추출한다. 원본, 중간자료, 최종 분석자료를 분리하고 각 단계의 입력·출력과 행 수를 기록한다. 데이터가 큰 경우 공간 인덱스 또는 공간 필터가 가능한 도구로 처리한다.
4. **통항 특성 산출**: 선종별 항적 지도를 만들고 월별 항적 수와 고유 MMSI 수를 별도로 집계한다. 월은 제안서에 따라 항적 시작 시각 기준으로 분류한다. 화물선과 유조선의 이용 격자 및 월별 변화도 비교한다.
5. **우선구역 선정·민감도 분석**: 분석 영역을 250m·500m·1km 격자로 나누고, 기본 결과는 500m 격자 및 관측 선박이 있는 셀 중 고유 MMSI 수 상위 10%로 제시한다. 상위 20% 기준도 비교한다. 격자별 고유 MMSI 수와 선종별 이용 규모를 계산하고, 월별 후보 유지 정도를 살핀다. 공통 공간 기준으로 후보 중첩 면적 비율과 위치 변화를 비교한다.
6. **결과 정리**: 선종별 경로 지도, 월별 통계, 우선구역 지도 및 선정 근거표를 산출한다. 그림과 표에는 자료 기간, 집계 단위, 격자 크기, 후보 기준 및 해석상 한계를 함께 기록한다.

## 기본 프로젝트 구조

```text
data/
  raw/          # 내려받은 원본(대용량, 버전관리 제외)
  interim/      # 좌표계 변환·지역 추출 등 중간 결과
  processed/    # 분석에 바로 쓰는 정제 자료
  notebooks/    # 자료 확보·점검·통계 분석 노트북
configs/        # 실행 및 분석 설정 JSON
docs/           # 제안서, 메모, 결과 보고서
src/            # 재사용 가능한 Python 모듈과 실행 진입점
outputs/        # 표·그림·분석 산출물
visualization/  # 산출물 탐색·표현 인터페이스(방식은 추후 결정)
```

초기 구현 순서는 `Config` 객체와 공통 설정 전달 흐름 → 자료 메타데이터·품질 점검 → 지역·좌표계 전처리 → 항적/월별 집계 → 격자 및 민감도 산출 → 시각화로 제안한다. JSON에는 기간, 항만/분석 경계 경로, 입력·출력 경로, 선종, 투영좌표계, 격자 크기 목록, 상위 비율 기준 등을 두고, 실행별 변경값은 설정 파일로 바꾸도록 한다. `Config` 클래스는 설정 검증과 경로 해석을 맡기며 런타임의 각 단계에 같은 설정 객체를 전달한다. 현재 단계에서는 `.py` 실행 코드는 작성하지 않고 구조와 첫 통계 분석 노트북만 준비한다.

## 연구 진행 중 결정이 필요한 사항

- Norfolk/Hampton Roads의 구체적인 분석 경계(전자해도 기준 경계 파일 및 버전)와 경계 안팎 항적의 포함 규칙
- 제안서의 ‘화물선’ 및 ‘유조선’을 원자료의 어떤 `VesselGroup`/선종 코드와 연결할지, 기타·미상 유형을 제외할지
- NOAA 월별 GeoParquet 항적 자료를 기본 자료로 확정할지, 원시 AIS 위치 자료를 추가로 확보할지(후자는 2024년 전국 합계가 약 116.7GB)
- 정제된 지역 자료 및 산출물의 보존 형식(예: GeoParquet/Parquet, CSV, GeoPackage)과 저장 위치·공유 방식
- 우선구역 상위 비율의 기준 모집단(전체 격자 또는 관측 MMSI가 1개 이상인 격자)과 동률 처리 방법
- 월별 분석에서 항적 시작월 기준을 유지할지, 항적 교차 월 기준 분석을 보조 결과로 추가할지
- 결과물에 필요한 지도 범위, 보고서 형식 및 팀원별 역할·검토 일정
